# Assignment 6: Multi-threaded Data Processing System

## Overview

This project implements a Multi-threaded Data Processing System in Java and Go. The system uses multiple workers to process tasks concurrently from a shared task queue.

## Java Implementation

The Java implementation demonstrates:
- Multiple worker threads
- Shared task queue
- Synchronization
- Exception handling using try-catch
- InterruptedException handling
- Thread joining using join()

## Go Implementation

The Go implementation demonstrates:
- Goroutines
- Channels
- Concurrent task processing
- Error handling
- Concurrent worker execution

## System Testing

Both implementations were successfully executed using ten tasks and three workers. The programs completed processing successfully and displayed the processed results.

## Files

- `DataProcessingSystem.java` – Java implementation
- `main.go` – Go implementation
